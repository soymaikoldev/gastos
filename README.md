# Mis Gastos

Registro rápido de gastos diarios — privado, estilo Content Hub.

- Repo **público**: solo el cascarón (diseño + lógica), **sin ningún dato personal**.
- Los gastos viven en el repo **privado** `content-hub-data`, archivo `gastos.json`, y se cargan con un token de GitHub guardado en el navegador (el mismo del Content Hub y del tablero — mismo origen `soymaikoldev.github.io`).
- Sin token: solo se ve una pantalla de bloqueo.

Captura de 2 toques (monto · moneda Bs/$ · categoría), totales Hoy/Semana/Mes en USD, desglose por categoría y detector de "gasto hormiga". Desplegado en GitHub Pages.
